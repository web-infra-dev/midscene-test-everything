# Midscene Robotics

[English](./README.md) · 简体中文 · [Midscene.js](https://midscenejs.com/zh/)

用摄像头和机械臂，让 Midscene 操作真实触摸屏。提供浏览器工作台、Node.js SDK 和 DOBOT MG400 适配器。

## 快速开始

准备带触控笔的 MG400、摄像头和触屏设备，使用 Node.js `^20.19.0 || ^22.12.0 || >=24.0.0` 和 pnpm 9.3.0。

```sh
pnpm install
pnpm build
pnpm dev
```

打开终端输出的网址。Playground 会探测 `192.168.1.6` 和 `192.168.2.6`，优先连接唯一一台可响应 Dashboard 指令的 MG400。如果只有一台控制器应答，但它拒绝 Dashboard 指令，适配器会自动请求切换到 TCP/IP 开发模式，并重新查询确认。都未找到时，可以重试或点「跳过，查看相机」预览实时画面。跳过后仍使用正常工作区布局；点击侧栏准备进度中的「连接机械臂」打开连接弹窗，相机画面保持可见。如需指定地址、端口或配置网口，使用 `pnpm dev --manual` 启动。连接成功后按引导标定并配置模型，即可执行任务。运动前确认工作区安全，需要停止时点击「停止机械臂」。

点击相机预览中的「识别屏幕标记」或机械臂配置中的「屏幕标定」，Playground 会使用这台相机已经连接的手机。手机配对链接自动优先使用电脑当前的 Wi‑Fi，排除机械臂有线网段和虚拟网卡。首次连接时扫码一次，保持页面在前台。手机立即请求常亮，在局域网 HTTP 下自动播放白色静音背景视频。Android 自动请求全屏；浏览器要求手势时，点手机上的「进入全屏」。鸿蒙按提示进入全屏。iOS 在 Safari 中选择「分享 → 添加到主屏幕」，再从主屏幕图标打开。只有手机进入所需模式并显示标记后，才开始采图。返回 Playground 首页后，手机标定页保持全屏，下次运行可直接复用。

Playground 对同一批 8 张相机帧统一解码，按屏独立拟合。高置信度结果可自动应用，置信不足或部分成功时可逐屏复核，只重试受影响的屏幕。实时轮廓检查发现错位时，可在复核中确认后应用视觉结果。依赖图像的运动仍要求透视和页面映射有效。仅相机模式下，识别完成后会打开透视校正界面，可对照原始画面与校正结果、编辑四角、设置输出尺寸与旋转，最后点击「使用此结果」保存。

Playground 会自动根据实时画面检查每块已保存屏幕的轮廓。同一套本地几何检测覆盖保存校正前、SDK 截图和触控前、标定阶段切换、采集过程，以及多屏批次取得 Controller 队列和恢复执行时。确认偏移后会阻止继续执行依赖图像的运动，并标明受影响的屏幕，提供重新校正入口。低对比度或遮挡保持“未确认”，不能清除已确认的偏移；恢复需要至少三帧独立的对齐画面，时间跨度不少于 1.5 秒。检测证据与几何数据分开保存，不改变映射指纹，也不自动删除已接受的标定。相机故障、旧帧、取消和手机布局变化均不能使等待中的旧命令继续启动运动。

相机标定时，请让手机上的六个标定码都保持可见。低对比度画面出现漏检时，系统会增强对比度并重试一次。

引导依次完成「触控工具 → 相机映射 → 示教安装 → 屏幕标定」。实时相机画面贯穿引导，包括手机绑定和队列等待；宽窗口并排展示，窄窗口固定在操作区上方。在「示教安装」中，先在屏幕中心上方 20–50 mm 记录标定参考位。选择「示教相机边界」，从参考位朝相机方向直线移动，为整条机械臂留足空间，在距离参考位至少 20 mm 的安全边界记录位置；确认通行区域后保存安装示教。同一机械臂、工具、相机的多块屏幕共用这份示教；机械臂或工具几何变化后需重新示教。参考位定义普通横移的最低通行高度，接触探索仍受向下搜索距离限制。

保存「触控工具」后，实测长度和负载会在屏幕标定前保存。重新打开机械臂配置时，引导会根据已保存的进度打开下一步，前几步已完成时直接进入「屏幕标定」。需要修改时，可以点击顶部的对应步骤。使能时使用已保存的负载，仍需操作员确认。同一机械臂和相机下，如果已保存的配置使用同一工具，尚未配置的屏幕可复用这份测量值。

采集、拟合并自动检查边界后，有效示教会授权自动计算相机安全位：依次预检左右两侧出口，再考虑相机对侧；先抬到示教通行高度，再以配置速度和加速度的 10% 移动。实测到位后才记录安全位。停车位置会避开已知屏幕的合并范围，包括屏幕之间的空隙。候选均不可达时回退手动记录安全位；已经提交的运动失败则中断标定。检查结果后确认保存。

在「相机映射」中，用每台设备打开手机页，再在电脑上选择页面及观察它的相机。二维码也可用于打开手机页。浏览器会保留稳定的页面身份，标记检测步骤将页面绑定到屏幕目标。应用后，原始画面显示各屏轮廓，校正预览随选中的屏幕切换。「返回首页」释放页面会话，「清除透视」保留该屏已保存的结果。删除屏幕绑定、删除已保存的透视和忘记离线页面分别操作。

「屏幕标定」保留原版逐屏卡片、计划顺序、摆位提示、运行历史与队列确认。整个标定及人工等待期间共用并占用同一个 Controller 队列。单屏标定排队时，也必须等到取得队列使用权才能采集。已有结果提供实测起点；新屏幕可从已接受屏幕推算平面，或等待人工摆位。启动前需确认屏幕固定，以及适用时的跨屏通行区域。自动接受要求实测几何、完整边界验证和实测到位的相机避让安全位，否则等待人工复核。重试、跳过只影响当前屏。停止优先中断待执行命令，退出拖动模式后再释放队列，并保留已完成结果；服务重启后保留历史并停止，等待显式恢复。恢复时保留已确认的通行高度，并重新核对几何、示教、屏幕映射，以及当前位置是否仍在确认的通行区域内。完成后通过屏幕选择器切换预览与任务。SDK 中为每屏设置独立的 `RobotArmDevice.id` 和 `screenId`，物理 `camera` 保持相同。

顶部工具栏的扬声器图标控制中英文浏览器语音与简短进度音效。提示覆盖标记拍摄倒计时、标定运动、相机避让、结果确认、机械臂报警和停止结果。语音跟随界面语言，需要先与浏览器交互，隐藏标签页保持静音，播放故障不会阻塞机械臂指令。采样点固定内缩 10%，拟合覆盖率至少为完整屏幕的 60%。快速和滑动模式要求屏幕固定且水平。 在机械臂标定中，可点「上一步」回看已完成步骤的测量记录，再点「下一步」返回当前进度。

## SDK 与适配器

使用方式见 [SDK 示例](./examples/mg400/run.mjs)。接入其他机械臂时，实现 `@midscene/arm-kit/adapter-development` 中的 `RobotArmAdapter`，可参考 [MG400 适配器](./packages/adapter-mg400/src/mg400.ts)。

## 目录结构

```text
packages/arm-kit/           Node.js SDK
packages/adapter-mg400/     MG400 适配器
packages/calibration-ui/    标定界面
packages/shared/            共享类型与工具
packages/playground/        可复用工作台
apps/playground/            MG400 工作台启动入口
examples/mg400/             SDK 示例
```

标定代码在 `packages/arm-kit/src/calibration`，包含手机与相机配置、采集拟合、边界验证。
