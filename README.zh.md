# Midscene Robotics

[English](./README.md) · 简体中文 · [Midscene.js](https://midscenejs.com/zh/)

用摄像头和机械臂，让 Midscene 操作真实触摸屏。提供浏览器工作台、Node.js SDK 和 DOBOT MG400 适配器。

## 快速开始

准备带触控笔的 MG400、摄像头和触屏设备，使用 Node.js `^20.19.0 || ^22.12.0 || >=24.0.0` 和 pnpm 9.3.0。

```sh
pnpm install
pnpm build
pnpm dev
```

打开终端输出的网址。Playground 会探测 `192.168.1.6` 和 `192.168.2.6`，优先连接唯一一台可响应 Dashboard 指令的 MG400。如果只有一台控制器应答，但它拒绝 Dashboard 指令，适配器会自动请求切换到 TCP/IP 开发模式，并重新查询确认。探测期间也可以点「跳过，查看相机」。两个入口使用同一个相机工作区，可以稍后在侧栏点「连接机械臂」。连接或断开后工作区保持打开；所选相机和视图仍可用时会保留。如需指定地址、端口或配置网口，使用 `pnpm dev --manual` 启动。连接成功后按引导标定并配置模型，即可执行任务。运动前确认工作区安全，需要停止时点击「停止机械臂」。若提示需要恢复，确认机械臂静止后点击「检查恢复」。

点击相机预览中的「识别屏幕标记」或机械臂配置中的「屏幕标定」，Playground 会使用这台相机已经连接的手机。手机配对链接自动优先使用电脑当前的 Wi‑Fi，排除机械臂有线网段和虚拟网卡。首次连接时扫码一次，保持页面在前台。可以先跳过机械臂连接，识别标记并保存透视。连接后，已配对手机的结果归到原来绑定的屏幕；新手机可以使用尚未绑定的默认屏幕。打开对应屏幕的标定向导即可在原手机上继续，无需再次扫码，其他手机不会覆盖已绑定屏幕的结果。手机优先请求系统常亮；安卓不创建唤醒视频，避免全屏被浏览器播放器接管，仅在 HTTPS 页面使用系统常亮。点手机上的「进入全屏」后，Android 通过浏览器全屏 API 进入全屏，并保持扫码时手机的横竖屏方向，不会主动切换系统方向。鸿蒙按提示进入全屏。iOS 在 Safari 中选择「分享 → 添加到主屏幕」，再从主屏幕图标打开。只有手机进入所需模式并显示标记后，才开始采图。返回 Playground 首页后，手机标定页保持全屏，下次运行可直接复用。

Playground 对同一批 8 张相机帧统一解码，按屏独立拟合。有效帧不足时，仅对受影响的屏幕自动重试最多两轮，每轮重新采集 8 帧。高置信度结果可自动应用，置信不足或部分成功时可逐屏复核，只重试受影响的屏幕。实时轮廓检查发现错位时，可在复核中确认后应用视觉结果。依赖图像的运动仍要求透视和页面映射有效。无论机械臂是否连接，都可以点击「编辑透视」，用所选相机的最新帧调整透视。仅相机模式下，识别完成后也会打开透视校正界面，可对照原始画面与校正结果、编辑四角、设置输出尺寸与旋转，最后点击「使用此结果」保存。 保存后，相机预览会按所选屏幕保存的宽高比显示校正画面，可在「原始画面」和「校正画面」之间切换。仅相机模式下，「清除透视校正」会删除保存的屏幕轮廓、输出尺寸和旋转，并返回原始画面。连接机械臂后，从预览或「相机映射」清除透视会解除所选屏幕的映射，并保留其已存透视。

Playground 只用配对手机在前台以所需显示模式打开标定页期间采集的相机帧，自动检查该屏幕已保存的轮廓。切换 App、锁屏、返回手机等待页或连接中断时会暂停自动检查。回到标定页后会用新帧恢复检查。暂停期间，SDK 截图和触控、标定采样及多屏批次仍受此前已确认的偏移限制。确认偏移后会阻止继续执行依赖图像的运动，并标明受影响的屏幕，提供重新校正入口。低对比度或遮挡保持“未确认”，不能清除已确认的偏移；恢复需要至少三帧独立的对齐画面，时间跨度不少于 1.5 秒。检测证据与几何数据分开保存，不改变映射指纹，也不自动删除已接受的标定。相机故障、旧帧、取消和手机布局变化均不能使等待中的旧命令继续启动运动。

预览中的绿框表示已应用的透视范围。页面映射校验失败时，手机会继续显示标定码，可以直接重试「确认相机映射」。相机映射允许机械臂遮住手机上六个标定码中的任意一个。出现漏检时，系统会增强对比度并重试一次。至少需要唯一识别出五个标定码。每个可见标定码取四个角点中最大的定位误差。拟合码和独立校验码分组计算，相对于手机页面短边，平均误差建议在 0.75% 以内，最大误差建议在 1% 以内。每项建议值有 10% 的相对容差，超出容差的映射仍可查看和复核。

引导依次完成「触控工具 → 相机映射 → 示教安装 → 屏幕标定」。步骤栏固定在顶部，操作区与实时相机预览共用一个滚动区；宽窗口左右并排，窄窗口把预览放在操作区上方。预览区可以切换「实时预览」和当前步骤的「配置示意图」，无需离开当前步骤。在「示教安装」中，先在屏幕中心上方 20–50 mm 记录标定参考位。选择「示教相机边界」，从参考位朝相机方向直线移动，为整条机械臂留足空间，在距离参考位至少 20 mm 的安全边界记录位置；确认通行区域后保存安装示教。同一机械臂、工具、相机的多块屏幕共用这份示教；机械臂或工具几何变化后需重新示教。前往相机侧边界、手动返回参考位和自动采样前返回参考位，都使用当前配置的动作速度和加速度。参考位定义普通横移的最低通行高度，接触探索仍受向下搜索距离限制。

在相机原始预览中，蓝色圆点表示标定参考位，黄色菱形表示已记录的安全避让位。屏幕几何拟合前，参考位显示在映射屏幕的中心。拟合后，标记按笔尖在屏幕平面上的垂直投影绘制。已记录的相机侧边界点落在画面内时，以紫色三角标出。参考位或安全避让位超出视野时标为「画面外」。

保存「触控工具」后，实测长度和负载会在屏幕标定前保存。重新打开机械臂配置时，引导会根据已保存的进度打开下一步，前几步已完成时直接进入「屏幕标定」。需要修改时，可以点击顶部的对应步骤。使能时使用已保存的负载，仍需操作员确认。同一机械臂和相机下，如果已保存的配置使用同一工具，尚未配置的屏幕可复用这份测量值。

探测运动确认到位、手机读数明确后，如果采样或拟合未通过，机械臂会先预检回程路线，原地抬笔，再回到本次记录的标定参考位，等待重试。停止、断连、手机读数不确定或运动结果未确认时会中断自动回位。

每次探测到位后，机械臂保持静止，等待手机两次读数一致，两次读数至少间隔 100 毫秒。在下探下限、最终按压或滑动终点，如果手机初次回报未接触，会先等一个完整的手机上报周期（750 毫秒）再请求确认。触点出现较晚或坐标变化时，会在同一高度再读一次。五秒内缺少本步回包、浏览器取消触点或按压时短暂接触后又释放，都会在当前位置停止采样。失败审计的 `detail.phoneObservations` 记录最近的探测高度、目的、手机回包序号，以及从发出请求到收到回包的用时，其中包含浏览器处理时间。

采集、拟合并自动检查边界后，有效示教会授权自动计算相机安全位：依次预检左右两侧出口，再考虑相机对侧；先抬到示教通行高度，再以配置速度和加速度的 10% 移动。实测到位后才记录安全位。停车位置会避开已知屏幕的合并范围，包括屏幕之间的空隙。候选均不可达时回退手动记录安全位；已经提交的运动失败则中断标定。检查结果后确认保存。

网格均方根误差和独立验证点的最大触点误差同时显示毫米值和占实测屏幕短边的百分比，建议值分别为 1% 和 1.5%。高度误差按 2 mm 表面补偿范围计算。各项质量指标均有 10% 的相对容差，例如覆盖率目标为 60%，实测 54% 仍在容差内。超出容差会保留采样和拟合结果。复核后可直接继续边界验证，也可以重新采样。保存前需要完成边界验证并记录安全位置，批量标定遇到质量提示时进入人工验收。

在「相机映射」中，用每台设备打开手机页，再在电脑上选择页面及观察它的相机。二维码也可用于打开手机页。浏览器会保留稳定的页面身份，标记检测步骤将页面绑定到屏幕目标。应用后，「原始画面」显示所有已保存的屏幕轮廓。选择屏幕并切换到「校正画面」，即可按保存的宽高比单独查看这块屏的实时透视画面，完成机械屏幕标定前也能查看。「返回首页」释放页面会话，「清除透视」保留该屏已保存的结果。删除屏幕绑定、删除已保存的透视和忘记离线页面分别操作。

机械臂已连接且所选屏幕已完成标定和相机映射后，可在机械臂状态栏打开「控制」。点击为点击，按住至少 500 ms 为长按，拖动为滑动，手势在释放时执行。在「原始画面」中，指针下的屏幕即为目标；在「校正画面」中，目标为当前选中的屏幕。触摸另一块物理屏幕前，必须先验证该方向的设备切换路径。Playground 会在移动前请求确认；没有已验证路径时直接拒绝动作，机械臂不会移动。任务或标定运行期间，以及机械臂未就绪时，控制不可用。

当前屏幕已有可用的示教参考位时，向导直接进入采样准备。服务重启后，打开原屏幕会重新关联已配对的手机。向导复用通过失效检测的已保存透视。手机布局、相机指纹和工具几何一致时，直接恢复页面坐标映射。如果只缺页面映射，向导使用已保存的校正画面检查标记，成功后自动继续。透视缺失或失效时进入「相机映射」进行检测。每块屏首次运动前（包括批量标定），若控制器短暂断连或负载回读暂不可用，向导会短暂等待。负载与已保存配置一致且机械臂就绪后，会根据最新位姿重新检查路线并继续。若控制器负载与保存值不一致，请同步工具负载。采样中若只有手机或控制器连接中断，原设备重连后会重新核对屏幕映射、位姿及静止无报警状态，清除本轮采样点并返回采样准备。再次采样需手动启动。手动停止、急停或运动结果未确认时，仍需人工确认恢复。只有一块已映射屏幕时，「屏幕标定」直接打开该屏幕的标定页面。有多块屏幕时，「标定 [屏幕名称]」只标定当前选中的屏幕。进行中如需换屏，先取消本次标定。重试会保留该屏幕的手机配对和相机映射，从零开始采样；通过验证并保存后才会替换该屏幕原有的结果。「批量标定多个屏幕」有独立的确认入口。

「屏幕标定」保留原版逐屏卡片、计划顺序、摆位提示、运行历史与队列确认。整个标定及人工等待期间共用并占用同一个 Controller 队列。单屏标定排队时，也必须等到取得队列使用权才能采集。已有结果提供实测起点；新屏幕可从已接受屏幕推算平面，或等待人工摆位。启动前需确认屏幕固定，以及适用时的跨屏通行区域。 批量默认使用「普通」逐点采样。选择「快速」后，每块屏使用滑动采样，需确认所有屏幕均已水平固定。两种模式默认在采样质量和完整的悬停、接触边界验证通过后自动验收，也可选择逐屏人工验收。批量等待当前手机页面就绪，逐屏完成验证并保存结果，随后转场至下一块。移动到共用安全位前，会先确认所有配对手机能显示验证图案。若检查失败，可在批量面板重试避让并保留已保存的逐屏结果。最后一块结束后，才根据实测轮廓及跳过屏幕的保守估算搜索共用安全位。避让时法兰和笔尖须向远离相机的一侧移动，目标与已示教的相机边界至少相隔 20 mm。每次到达可行候选位置后，配对手机会短暂交替显示棋盘格。只有新鲜相机帧确认各屏都能看到预期图案，才记录该位置。部分遮挡时会尝试下一个通过路线检查的位置，每轮最多尝试三个新候选，XY 位移限制在距实测搜索起点 500 mm 内。候选耗尽或画面无法验证时停止搜索。各屏的标定结果在共用安全位通过画面检查并统一保存后，才可用于任务。重试或恢复时沿用所选采样模式及已记录的共用安全位。重试、跳过只影响当前屏。停止优先中断待执行命令，退出拖动模式后再释放队列，并保留已完成结果；服务重启后保留历史并停止，等待显式恢复。恢复时保留已确认的通行高度，并重新核对几何、示教、屏幕映射，以及当前位置是否仍在确认的通行区域内。完成后通过屏幕选择器切换预览与任务。SDK 中为每屏设置独立的 `RobotArmDevice.id` 和 `screenId`，物理 `camera` 保持相同。

顶部工具栏的扬声器图标控制中英文浏览器语音与简短进度音效。手机显示模式、标记拍摄倒计时、相机映射和安装示教都有语音提示。确认快速采样时，会提醒将手机水平固定，采样时请勿手持。机械臂前往参考位、采集网格点、沿边界悬停、接触屏幕和避让相机时会分别播报。采样或拟合检查后，若机械臂准备抬起并返回参考位，页面会同时播报并显示返程提示。需要复核测量偏差、手动记录安全位、为下一块屏幕摆放触笔或确认保存时，语音会提示下一步。运动提醒优先于普通进度，机械臂报警和停止结果优先级最高。语音跟随界面语言，需要先与浏览器交互，隐藏标签页保持静音，播放故障不会阻塞机械臂指令。

采样点固定内缩 10%，目标覆盖完整屏幕的 60%。默认选中「快速」，滑动采样；「普通」模式以配置动作速度和加速度的 10% 逐点探测，最后下压采集触点时，两者提高到配置值的 25%。网格采样时，手机与网页示意图同步显示九个编号采样点，虚线连接采样顺序，蓝圈标出当前目标，绿点标出已记录的实际触点。快速采样的首个网格点未检测到触摸时，系统朝初始实测触点内移 3 mm 重试一次，下探限位保持不变。快速采样失败时，点击「确认重试」后才会切到普通模式重新采样。快速模式下，一次勾选即可确认屏幕水平固定、配置就绪且工作区净空。在机械臂标定中，可点「上一步」回看已完成步骤的测量记录，再点「下一步」返回当前进度。

刷新单屏标定页会恢复本轮进度，可以继续查看测量值或已保存的结果。等待边界验证时仍可取消本次标定。中断后页面会显示出错的步骤，控制器需要恢复时可点击「检查并恢复控制器」。在 SDK 独立页保存后，点击「完成标定」即可把结果返回脚本。再次从 SDK 发起标定会开始新的一轮，即使这块屏幕已有保存的标定结果。

安全位的画面验证根据手机上报的网页视口和相机中的棋盘格定位，排除网页之外的系统栏。验证允许少量零散漏检，网页内部各格仍须达到局部检出要求。如果首组画面检出率未通过，机械臂保持原位，相机补采一组画面再决定是否继续搜索。批量面板分别显示已保存的屏幕标定结果和待确认的共用安全位。安全位待确认时，可查看实时画面后人工确认当前位置。控制器检查静止时的实测位置是否满足安全位条件，并原地记录确认结果。

当前相机下的所有屏幕就绪后，点击「完成标定并返回」回到 Playground。首页会重新检查当前生效的标定，再显示任务界面。

## SDK 与适配器

使用方式见 [SDK 示例](./examples/mg400/run.mjs)。`RobotArmDevice.perform(action)` 可按屏幕像素执行绝对的点击、长按、滑动或拖拽；Device 会自行解析已接受的标定和相机映射，并拒绝屏幕范围外的点。接入其他机械臂时，实现 `@midscene/arm-kit/adapter-development` 中的 `RobotArmAdapter`，可参考 [MG400 适配器](./packages/adapter-mg400/src/mg400.ts)。

## 目录结构

```text
packages/arm-kit/           Node.js SDK
packages/adapter-mg400/     MG400 适配器
packages/calibration-ui/    标定界面
packages/shared/            共享类型与工具
packages/playground/        可复用工作台
apps/playground/            MG400 工作台启动入口
examples/mg400/             SDK 示例
```

标定代码在 `packages/arm-kit/src/calibration`，包含手机与相机配置、采集拟合、边界验证。
